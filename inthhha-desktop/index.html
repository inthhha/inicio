INTHHHA - Desktop

Aplicación Web construida a partir de Tauri y Rust, tiene por finalidad la utilización de los mismos recursos de la presente página web a nivel local.

¿QUE VENTAJAS TIENE USARLO?

  • Mayor velocidad al cargarse de manera local.
  • Gran parte de sus funciones no depende de Internet.
  • Acceso seguro, no se recopilan ni extraen datos del usuario o los respectivos servidores.
  • Instalación y uso de bajo consumo y almacenamiento.
